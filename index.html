Tujuan Pembelajaran

Setelah mempelajari materi ini, kamu diharapkan mampu:

  • Menjelaskan makna turunan sebagai laju perubahan sesaat atau kemiringan garis singgung.
  • Menentukan turunan fungsi aljabar menggunakan aturan pangkat, penjumlahan, pengurangan, perkalian, dan pembagian.
  • Menentukan interval fungsi naik dan turun melalui tanda turunan pertama.
  • Menentukan titik stasioner serta nilai maksimum atau minimum dalam masalah kontekstual.
  • Menyampaikan alasan dan langkah penyelesaian secara runtut.
Pesan guru: Jangan terburu-buru menghafal rumus. Pahami pola, tulis setiap langkah, dan periksa kembali hasilmu.
Bagian 1

Konsep Dasar Turunan Fungsi Aljabar

Bayangkan sebuah sepeda yang bergerak. Jarak tempuh berubah terhadap waktu. Turunan membantu kita mengetahui seberapa cepat perubahan itu terjadi pada suatu saat. Dalam grafik fungsi, turunan di suatu titik menyatakan kemiringan garis singgung.

Jika y = f(x), maka turunannya ditulis f'(x) atau dy/dx.

Secara sederhana, jika gradien positif grafik sedang naik; jika gradien negatif grafik sedang turun; dan jika gradien nol, grafik memiliki garis singgung mendatar (titik stasioner).

Turunan positif
f'(x) > 0 → fungsi naik pada interval tersebut.
Turunan negatif
f'(x) < 0 → fungsi turun pada interval tersebut.

A. Aturan pangkat: xⁿ

Jika f(x) = xⁿ, maka f'(x) = n · xⁿ⁻¹

Artinya: pangkat turun menjadi pengali, kemudian pangkat dikurangi satu.

Contoh 1 — bentuk paling sederhana

Tentukan turunan f(x) = x⁵.

  1. Pangkatnya adalah 5.
  2. Turunkan pangkat 5 menjadi pengali.
  3. Kurangi pangkat x satu tingkat.
f'(x) = 5x⁴

Contoh 2 — koefisien dan konstanta

f(x) = 4x³ − 7x² + 6x − 9

  1. Turunan 4x³ adalah 4 × 3x² = 12x².
  2. Turunan −7x² adalah −7 × 2x = −14x.
  3. Turunan 6x adalah 6.
  4. Turunan konstanta −9 adalah 0.
f'(x) = 12x² − 14x + 6

B. Bentuk u berpangkat n

Jika y = [u(x)]ⁿ, maka y' = n[u(x)]ⁿ⁻¹ · u'(x)

Ini disebut aturan rantai. Turunkan bagian luar terlebih dahulu, lalu kalikan dengan turunan bagian dalam.

Contoh 3

y = (2x + 3)⁴

  1. Bagian luar berpangkat 4, sehingga menjadi 4(2x + 3)³.
  2. Turunan bagian dalam 2x + 3 adalah 2.
  3. Kalikan keduanya.
y' = 4(2x + 3)³ × 2 = 8(2x + 3)³

Contoh 4 — pangkat negatif dan akar

y = √(3x + 1) = (3x + 1)¹ᐟ²

  1. Ubah akar menjadi pangkat 1/2.
  2. Turunkan pangkat luar: ½(3x + 1)⁻¹ᐟ².
  3. Kalikan turunan bagian dalam, yaitu 3.
y' = 3/[2√(3x + 1)]

Ingat: bentuk akar dapat diubah menjadi pangkat pecahan sebelum diturunkan.

Bagian 2

Aturan Penjumlahan dan Pengurangan

Turunan dari penjumlahan atau pengurangan beberapa fungsi dapat dikerjakan per suku. Tanda positif dan negatif harus tetap diperhatikan.

[u(x) ± v(x)]' = u'(x) ± v'(x)

Contoh 5

f(x) = 3x⁴ + 2x³ − 5x² + 8x − 11

  1. Turunkan 3x⁴ → 12x³.
  2. Turunkan 2x³ → 6x².
  3. Turunkan −5x² → −10x.
  4. Turunkan 8x → 8, sedangkan −11 → 0.
  5. Gabungkan semua hasil dengan tanda semula.
f'(x) = 12x³ + 6x² − 10x + 8
Bagian 3

Turunan Perkalian dan Pembagian

A. Aturan perkalian

Jika y = u · v, maka y' = u'v + uv'

Turunkan fungsi pertama, kalikan fungsi kedua; lalu tambahkan fungsi pertama dikalikan turunan fungsi kedua.

Contoh 6

y = (x² + 1)(x³ − 2x)

  1. Tetapkan u = x² + 1 dan v = x³ − 2x.
  2. Turunkan: u' = 2x dan v' = 3x² − 2.
  3. Gunakan aturan perkalian: y' = u'v + uv'.
  4. Substitusikan: y' = 2x(x³ − 2x) + (x² + 1)(3x² − 2).
  5. Uraikan: 2x⁴ − 4x² + 3x⁴ + x² − 2.
  6. Gabungkan suku sejenis.
y' = 5x⁴ − 3x² − 2

B. Aturan pembagian

Jika y = u/v, maka y' = (u'v − uv')/v², dengan v ≠ 0.

Urutan pembilang penting: turunan atas × bawah, dikurangi atas × turunan bawah, kemudian dibagi kuadrat penyebut.

Contoh 7

y = (x² + 1)/(x + 2)

  1. u = x² + 1, sehingga u' = 2x.
  2. v = x + 2, sehingga v' = 1.
  3. Masukkan ke rumus: y' = [2x(x + 2) − (x² + 1)(1)]/(x + 2)².
  4. Uraikan pembilang: 2x² + 4x − x² − 1.
  5. Sederhanakan.
y' = (x² + 4x − 1)/(x + 2)²

Catatan: x tidak boleh −2 karena penyebut tidak boleh nol.

Strategi memilih aturan: Jika bentuknya jumlah/selisih, turunkan tiap suku. Jika dua fungsi dikalikan, gunakan aturan perkalian. Jika berupa pecahan dua fungsi, gunakan aturan pembagian. Jika fungsi berpangkat dengan isi kurung, gunakan aturan rantai.
Bagian 4

Penerapan: Interval Fungsi Naik dan Turun

Untuk mengetahui interval naik atau turun, kita periksa tanda turunan pertama.

f'(x) > 0 → fungsi naik
f'(x) < 0 → fungsi turun

Langkah menentukan interval

  1. Tentukan turunan pertama f'(x).
  2. Cari titik kritis dengan menyelesaikan f'(x) = 0. Perhatikan juga titik saat turunan tidak terdefinisi.
  3. Letakkan titik kritis pada garis bilangan sehingga terbentuk beberapa interval.
  4. Uji tanda f'(x) pada setiap interval.
  5. Simpulkan interval naik dan turun.

Contoh 8 — fungsi kuadrat

Tentukan interval naik dan turun dari f(x) = x² − 4x + 3.

  1. Turunkan: f'(x) = 2x − 4.
  2. Cari titik kritis: 2x − 4 = 0, maka x = 2.
  3. Uji interval x < 2, misalnya x = 0: f'(0) = −4 (negatif).
  4. Uji interval x > 2, misalnya x = 3: f'(3) = 2 (positif).
  5. Negatif berarti turun, positif berarti naik.
Turun pada (−∞, 2)
Naik pada (2, ∞)

Di x = 2, grafik mencapai titik minimum. Nilainya f(2) = 4 − 8 + 3 = −1, sehingga titik minimumnya (2, −1).

Contoh 9 — fungsi kubik

f(x) = x³ − 3x² − 9x + 5.

  1. Turunan: f'(x) = 3x² − 6x − 9.
  2. Faktorkan: f'(x) = 3(x² − 2x − 3) = 3(x − 3)(x + 1).
  3. Titik kritis: x = −1 dan x = 3.
  4. Uji x = −2: hasil positif; uji x = 0: hasil negatif; uji x = 4: hasil positif.
Naik pada (−∞, −1) dan (3, ∞)
Turun pada (−1, 3)

Perubahan tanda + ke − di x = −1 menunjukkan maksimum lokal; perubahan − ke + di x = 3 menunjukkan minimum lokal.

Bagian 5

Penerapan: Nilai Optimum (Maksimum dan Minimum)

Nilai optimum adalah nilai terbesar (maksimum) atau terkecil (minimum) yang dicapai suatu fungsi pada domain atau interval yang dibahas. Dalam banyak persoalan, turunan membantu menemukan titik kandidat optimum.

Titik stasioner diperoleh dari f'(x) = 0.

Untuk fungsi yang dapat diturunkan, uji perubahan tanda membantu mengidentifikasi jenis titik:

  • f' berubah dari positif ke negatif: maksimum lokal.
  • f' berubah dari negatif ke positif: minimum lokal.
  • Jika tanda tidak berubah, titik stasioner belum tentu maksimum atau minimum.

Contoh 10 — menentukan maksimum dan minimum

Diketahui f(x) = −x² + 6x + 7. Tentukan nilai maksimum.

  1. Turunan pertama: f'(x) = −2x + 6.
  2. Titik stasioner: −2x + 6 = 0, sehingga x = 3.
  3. Turunan kedua: f''(x) = −2. Karena negatif, grafik cekung ke bawah dan titik tersebut maksimum.
  4. Hitung nilai fungsi: f(3) = −9 + 18 + 7 = 16.
Nilai maksimum = 16, dicapai saat x = 3.

Contoh 11 — kasus kontekstual: pagar kebun

Seorang siswa memiliki 40 meter pagar untuk membuat kebun berbentuk persegi panjang. Salah satu sisi kebun menempel pada tembok sehingga sisi itu tidak perlu dipagari. Berapa ukuran kebun agar luasnya maksimum?

  1. Misalkan lebar yang tegak lurus tembok = x meter. Dua sisi lebar membutuhkan 2x meter pagar.
  2. Panjang sisi depan = 40 − 2x.
  3. Luas: L(x) = x(40 − 2x) = 40x − 2x².
  4. Turunan: L'(x) = 40 − 4x.
  5. Setarakan nol: 40 − 4x = 0, sehingga x = 10.
  6. Panjang = 40 − 2(10) = 20 meter.
  7. Luas = 10 × 20 = 200 m². Karena L''(x) = −4 (negatif), luas tersebut maksimum.
Ukuran optimal: 10 m × 20 m
Luas maksimum: 200 m²
Perhatikan domain: x harus lebih dari 0 dan kurang dari 20 agar kedua ukuran bernilai positif.

Contoh 12 — kasus ekonomi sederhana

Keuntungan suatu usaha kecil (dalam ratusan ribu rupiah) diperkirakan P(x) = −2x² + 24x − 40, dengan x banyaknya paket produk yang dijual dalam satuan puluhan paket. Tentukan jumlah paket yang menghasilkan keuntungan maksimum menurut model.

  1. P'(x) = −4x + 24.
  2. −4x + 24 = 0 → x = 6.
  3. P''(x) = −4, maka titik tersebut maksimum.
  4. P(6) = −72 + 144 − 40 = 32.
Model maksimum pada x = 6, yaitu 60 paket.
Keuntungan model = 32 ratus ribu = Rp3.200.000.

Model matematika adalah penyederhanaan keadaan nyata. Hasilnya tetap perlu disesuaikan dengan batas produksi dan kondisi usaha.

Catatan penting: Jika soal membatasi x pada interval tertutup [a,b], periksa juga nilai fungsi di kedua ujung interval, selain titik kritis di dalam interval. Nilai terbesar/terkecil global ditentukan dengan membandingkan semuanya.
